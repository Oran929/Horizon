## [OpenAI 发布 GPT-6 Astra，评测全面登顶](https://t.me/zaihuapd/43707) ⭐️ 10.0/10

OpenAI 发布了 GPT-6 Astra，称其为迄今最智能、最对齐的模型。它在 FrontierMath Tier 4 上得分 98%，在 ARC-AGI-3 上得分 99.9%，在 ExploitBench 上得分 100%，并帮助将素数间隔上界推进到 186。 此次发布标志着 AI 能力的一次重大飞跃，尤其是在数学推理和智能体任务方面，可能重塑对前沿模型的期待。基准测试结果表明，GPT-6 Astra 可能加速数学和网络安全领域的研究，而其定价和快速模式也可能影响行业标准。 GPT-6 Astra 在 OpenAI API 中的标准定价为每百万输入 token 10 美元，每百万输出 token 50 美元，缓存读取和写入另行收费。API 为 GPT-6 Astra 提供快速模式，处理速度最高可达标准模式的 2.5 倍。

## [OpenAI 的 Astra-next 在 88 小时内发现纳维-斯托克斯奇点](https://www.latent.space/p/ainews-openai-reports-navier-stokes) ⭐️ 9.0/10

OpenAI 报告称，其 Astra-next 系统使用约 10,000 个代理和 1300 亿个 token，在 88 小时内发现了纳维-斯托克斯方程中的奇点，成本超过 4000 万美元。这可能是第二个千禧年大奖解决方案的有力竞争者。 这可能是 AI 研究的一个突破性里程碑，因为解决千禧年大奖问题将是 AI 和数学领域的历史性成就。它展示了大规模 AI 系统在解决基础数学问题方面的能力，对 AI 驱动研究的未来具有重大意义。 该结果尚未得到克莱研究所或独立数学界的验证，并且存在优先权争议。OpenAI 表示，如果被授予千禧年大奖，他们将拒绝接受，类似于格里戈里·佩雷尔曼拒绝庞加莱猜想奖金的做法。

rss · Latent Space · 9月9日 05:04

## [vLLM v0.29.0：Model Runner V2 成为默认，新增模型并优化性能](https://github.com/vllm-project/vllm/releases/tag/v0.29.0) ⭐️ 8.0/10

vLLM v0.29.0 发布，包含来自 277 位贡献者的 594 次提交，Model Runner V2 成为所有模型的默认运行器。新增了对 Hy4-preview、Qwen3.8-Flash-Next、GraniteSWA 和 Kimi K3 等多个新模型的支持，并为 Kimi-K3 和 DeepSeek V4 带来了大量性能优化。 此版本标志着 vLLM 的一个重要里程碑，Model Runner V2 成为默认运行器，有望提升所有模型的模块化和性能。对 DeepSeek V4 和 Kimi K3 等前沿架构的新模型支持和优化，将使机器学习工程社区受益，实现更快、更高效的推理。 关键技术亮点包括用于 KV 缓存自动调整大小的 CUDA 图内存分析、减少每步 logits 内存的批量分片采样，以及新的默认设置，例如 TP CUDA 组默认启用 FlashInfer all-reduce。破坏性变更包括移除了十个已弃用的模型架构，并弃用 `python -m vllm.entrypoints.openai.api_server`，推荐使用 `vllm serve`。

github · khluu · 9月9日 08:54

**背景**: vLLM 是一个用于大型语言模型的高吞吐量、内存高效的推理和服务引擎。Model Runner V2 是 vLLM 推理核心的模块化重新设计，旨在提高性能和可维护性。诸如 MTP（多令牌预测）之类的推测解码技术允许模型提前草拟多个令牌并并行验证，从而加速生成。

## [Hugging Face Transformers v5.17.0 新增 HYV4 780B MoE 模型](https://github.com/huggingface/transformers/releases/tag/v5.17.0) ⭐️ 8.0/10

Hugging Face Transformers v5.17.0 新增了对 HYV4（Hy4-Preview）模型的支持，这是一个 780B 参数的混合专家语言模型，每个 token 激活 49B 参数。该版本还引入了 VibeVoice、NeoMME 和 Fun-ASR-Nano 模型。 该版本使社区能够尝试具有 MLA 和 DSA 等先进注意力机制的 780B 参数 MoE 模型，可能推动长上下文和高效推理的创新。同时，它还扩展了 Transformers 对多模态和语音模型的支持，影响这些领域的研究人员和开发者。 HYV4 使用多头潜在注意力（MLA）压缩键/值，采用带 IndexShare 的 DeepSeek 稀疏注意力（DSA）实现高效稀疏注意力，并具有可学习的注意力汇的门控 MLA，以及独立超连接（iHC）。实现忽略了多 token 预测（MTP）层，但发布的检查点保留了这些权重，以便其他运行时用于投机解码。

github · vasqu · 9月9日 15:42

**背景**: 混合专家（MoE）模型每个 token 只激活部分参数，从而在高效推理的同时实现更大的模型。多头潜在注意力（MLA）通过将键和值压缩到低秩潜在空间来减少 KV 缓存内存，而 DeepSeek 稀疏注意力（DSA）使用轻量级索引器选择 top-k 键，提高长上下文效率。IndexShare 通过在层间共享索引器选择进一步优化 DSA，降低计算开销。
